# Casino World

Python 텍스트 기반 미니 카지노 게임 - 6종 게임 + 로그인

##  실행 영상
[![실행 영상](https://img.youtube.com/vi/xHjpH9OR-LI/0.jpg)](https://youtu.be/xHjpH9OR-LI)

## 주요 기능
- 슬롯머신, 주사위, 홀짝, 숫자 맞추기, 경마, 카드 게임 (6종)
- 회원 로그인
- 배팅 시스템 및 잔고 관리

## 실행 방법
python Casino.py

## 사용 기술
- Python 3.x
- random 모듈을 활용한 게임 로직

## 배운 점
- 여러 게임을 메뉴 구조로 구성하는 방법
- 반복문과 조건문으로 게임 흐름 제어
